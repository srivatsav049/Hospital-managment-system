# Hospital Management System (C++, OOP Project)

## Overview
This project is a Hospital Management System developed using C++ and Object-Oriented Programming (OOP) principles. It is designed to streamline hospital operations by managing doctors, patients, appointments, treatments, and billing in an organized and efficient way. The system provides a menu-driven interface for easy interaction and ensures structured data handling.

---

## Problem Statement
Traditional hospital management methods are often manual and inefficient, leading to delays, poor record-keeping, and increased administrative workload. This project aims to address these issues by providing a digital solution to manage hospital operations effectively.

---

## Objectives
- Manage doctor and patient records efficiently  
- Schedule and organize appointments  
- Record and track treatments  
- Generate bills for patients  
- Provide easy access to hospital data  

---

## Concepts Used (OOP)
- **Classes & Objects** – Structured representation of entities like Doctor, Patient, etc.  
- **Inheritance** – Common properties shared through base classes  
- **Encapsulation** – Data and methods bundled within classes  
- **Polymorphism** – Method overriding for flexibility  
- **Abstraction** – Simplified interface hiding implementation details  

---

## Project Workflow
1. **Data Input**
   - Add doctor and patient details  
2. **Management System**
   - Store and manage records using vectors  
3. **Operations**
   - Schedule appointments  
   - Record treatments  
   - Generate bills  
4. **Output**
   - Display lists of doctors, patients, appointments, treatments, and bills  

---

## Features
- Add and manage doctors and patients  
- Appointment scheduling system  
- Treatment tracking  
- Billing system  
- Menu-driven user interface  
- Organized data storage using dynamic memory  

---

## Output
The system allows users to:
- View all records (doctors, patients, etc.)  
- Perform operations through a simple menu  
- Manage hospital workflows efficiently
